## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?
Ans,) If two PCs use the same IP address, the network gets confused and  communication problem occur. 

### 5.2 Why do we use a switch instead of directly connecting PCs together?
Ans,) We use switch because it lets multiple PCs communicate efficiently on the same network. 

### 5.3 What does the subnet mask 255.255.255.0 indicate?
Ans,) The subnet mask 255.255.255.0 indicates that devices are on the same network and can communicate  with each other.
